# AI Principles

## Project Overview
This repository contains the deliverable notebooks for the subject **AI Principles**. The work focuses on completing and understanding key tree search techniques through practical exercises.

## Included Notebooks
- Graph search algorithms notebook
- Maze search notebook
- Hill climbing notebook

## Objectives
The purpose of this project is to explore and apply fundamental AI concepts such as:
- Search strategies in graph problems
- Maze solving approaches
- Hill climbing optimization
